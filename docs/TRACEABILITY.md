# Phase 2 methodology traceability

| Document step | Implementation | Status / explicit limits |
|---|---|---|
| 1: task and causality | data.py, model.py, test_pipeline.py | Edge and node tasks; score-before-update; simultaneous timestamp handling |
| 2: collection | data.py, DATASETS.md, convert_xblock_graph.py | User downloads data; IBM CSV and configurable XBlock CSV/trusted multigraph conversion |
| 3: preprocessing | data.py | Disk-backed sort, no deduplication, train-only z-score and categories, strict time cuts |
| 4: features | data.py, StreamState | Directional histories and lifetime counts/volumes; recent count bounded by sampling |
| 5: DMT-GNN | model.py | Hierarchical attention, harmonic time, GRU, edge/node heads, focal loss, multi-group truncated BPTT |
| 6: baselines | tabular.py, model.py | XGBoost and merged DMT ready; internal TGN/Multi-GNN controls distinctly named; official reproductions and optional MEGA not integrated |
| 7: experimental design | experiments.py, streaming.py | 20-trial validation tuning, five seeds, freshness/load matrix; measured-service queue simulation |
| 8: metrics | metrics.py, streaming.py | Classification and queue/latency metrics; peak memory; incident detection delay requires extra annotations |
| 9: statistics | analysis.py | Paired two-level block bootstrap, Wilcoxon, Holm, Cliff's delta, rank-biserial |
| 10: ablations | model.py, configs | Merged, symmetric direction, no memory, single-stage, BCE and sampling budgets |
| 11: errors / cases | analysis.py, explain.py | Top FP/FN, strata, drift, true-positive deletion replay; no automated semantic taxonomy/GNNExplainer |
| 12: outputs | engine.py, analysis.py, scripts | Checkpoints and tables generated by runs; no invented trained real-data results or manuscript |

The supplied document is a proposed methodology, not a complete executable specification. Operational decisions and changes are disclosed in PROTOCOL.md. Full-scale datasets, hardware performance, official baseline reproduction and manuscript claims require empirical work after data acquisition.
